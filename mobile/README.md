# App mobile — Paróquia

App do fiel, em Expo/React Native com Expo Router. Fala com o [painel web](../web) via HTTP — nunca acessa o banco diretamente.

Instruções completas de configuração e uso: **[../docs/configuracao.md](../docs/configuracao.md)** e **[../docs/guia-de-uso.md](../docs/guia-de-uso.md)**.

Como publicar na App Store e no Google Play: **[../docs/publicacao-lojas.md](../docs/publicacao-lojas.md)**.

## Scripts

```bash
npm run start   # expo start — abre no Expo Go via QR code
npm run android  # expo start --android
npm run ios       # expo start --ios
npm run lint       # expo lint
```
